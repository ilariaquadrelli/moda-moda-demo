# Moda Moda - demo statica

Sito didattico fittizio composto da quattro pagine HTML responsive.

## Avvio
Aprire `index.html` in un browser oppure pubblicare l'intera cartella su GitHub Pages o Vercel. Non sono richiesti build, database o dipendenze.

## Struttura
- `index.html`: Home
- `chi-siamo.html`: identità dell'atelier
- `collezioni.html`: capi dimostrativi
- `contatti.html`: informazioni sull'appuntamento
- `assets/css/style.css`: stile condiviso
- `assets/js/main.js`: menu mobile
- `assets/images/`: immagini locali AI

## Nota
Il font viene caricato da Google Fonts; in assenza di rete vengono usati Georgia e Arial. I contatti sono dimostrativi e non attivi.
